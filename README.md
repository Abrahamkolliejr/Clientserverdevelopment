## 1. How do you write programs that are maintainable, readable, and adaptable?

When I write programs, I try to keep my code simple, organized, and easy to understand. In Project One, I created a CRUD Python module that allowed me to create, read, update, and delete information in a MongoDB database. I was able to use this same module in Project Two to connect my dashboard to the database. This made my work easier because I did not have to rewrite everything from the beginning. It also made fixing problems easier because the database code was separate from the dashboard code. In the future, I could use this module for other projects that need to store and manage information, such as inventory systems or customer databases.

## 2. How do you approach a problem as a computer scientist?

When I have a problem to solve, I first try to understand what needs to be done before I start writing code. For the Grazioso Salvare project, I had to create a dashboard that would help the company find animals that could be trained for rescue work. I started by working with the database and then connected it to the dashboard. I also tested the different filters to make sure they displayed the correct animals. This project was different from some of my previous assignments because I had to connect multiple parts of a program instead of working on just one thing. In the future, I would continue breaking big problems into smaller steps, testing my code, and making changes when something does not work.

## 3. What do computer scientists do, and why does it matter?

Computer scientists use technology and programming to solve problems and make tasks easier for people and businesses. Their work is important because it helps companies save time, organize information, and make better decisions. In my project, I created a dashboard that allows Grazioso Salvare to search for animals based on different rescue training categories. The dashboard also includes a chart showing animal breeds and a map showing animal locations. Instead of searching through thousands of records manually, the company can use the dashboard to find useful information much faster. This project helped me understand how computer science can make a difference in real-world situations.

## Conclusion

Overall, CS-340 taught me a lot about working with databases, Python, MongoDB, and dashboards. I learned how to connect different parts of a program and how important it is to write code that can be reused. I also learned that testing and fixing errors are important parts of programming. I believe the skills I learned in this course will help me become a better computer scientist and prepare me for future projects and jobs.
